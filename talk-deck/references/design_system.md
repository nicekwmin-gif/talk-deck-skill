# 디자인 체계

회사 템플릿이 있으면 템플릿의 글꼴·색·로고 위치가 우선이다. 그 경우에도 1절(피할 것)과 3·4절(글자 단계, 단어 수)은 지킨다.

## 1. "AI가 만든 슬라이드"로 보이는 증상 11가지

첫 렌더 뒤에 이 표로 덱을 점검한다. 해당하는 장 번호를 적고 고친다.

| # | 증상 | 왜 문제인가 | 대신 |
|---|---|---|---|
| 1 | 자간 넓힌 대문자 소제목(kicker) + 헤드라인 + 부제 3단 | 헤드라인 하나가 할 일을 세 줄로 나눈다 | 헤드라인 한 문장 |
| 2 | 번호 원, 아이콘 원, 장식 배지 | 정보 없이 "정리돼 보이는 효과"만 낸다 | 없앤다 |
| 3 | 알약(pill) 라벨, 상태 칩 | 대시보드 문법이다. 읽을 거리만 는다 | 본문 글자로 쓴다 |
| 4 | 크기가 같은 카드 격자(2×3, 3단 카드) | 모든 항목의 무게가 같아 핵심이 안 보인다 | 핵심 하나를 크게, 나머지는 작게 또는 말로 |
| 5 | 장마다 아래에 붙는 요약 띠 | 한 장에 메시지가 둘이 된다 | 헤드라인이 요약이다 |
| 6 | 섹션마다 다른 색, 무지개 색 코딩 | 색에 뜻이 없어진다 | 강조색 한 개, 뜻 하나 |
| 7 | 글자 크기가 장당 6종 이상 | 위계가 흐려지고 뒤에서 안 읽힌다 | 4단계만 |
| 8 | 장당 100단어 이상 | 청중이 읽기와 듣기를 동시에 해야 한다 | 40단어 이하, 나머지는 노트로 |
| 9 | 인용 5개 이상이 빽빽한 출처 줄 | 시선이 아래로 샌다 | 장당 3개까지, 전체 목록은 백업 장 |
| 10 | 같은 숫자·사례가 여러 장에 반복 | 공간을 채우려고 넣은 글로 보인다 | 한 번만 |
| 11 | 주황·빨강 경고색 단서 문구 | 덧붙인 면책문처럼 보여 신뢰가 떨어진다 | 헤드라인 안의 단어("예비 결과")나 회색 캡션 한 줄 |

그 밖에 피할 것: 이모지, 그림자, 그라데이션 도형, 내용과 안 맞는 사진(없으면 넣지 않는다), 여러 계열이 뒤엉킨 선 그래프, 글이 빽빽한 표.

## 2. 그리드 (16:9, 13.333 × 7.5 in. 좌표는 x, y, w, h in)

| 요소 | 값 |
|---|---|
| 여백 | 좌우 0.8, 위 0.7, 아래 0.55. 콘텐츠 폭 11.733 (x 0.8–12.533) |
| 헤드라인 | (0.8, 0.7, 11.0, 1.3) |
| 본문 영역 | y 2.2–6.6 |
| 출처 줄 | (0.8, 6.95, 10.8, 0.3) |
| 쪽번호 | (11.9, 6.95, 0.633, 0.3), 오른쪽 정렬 |
| 분할형 사진 | (0, 0, 5.333, 7.5). 글 칼럼은 x 6.0–12.533 |
| 세로 기준선 | 0.8 / 6.0 / 6.667 / 12.533 네 개만 쓴다 |

모든 장에서 헤드라인·출처·쪽번호의 위치가 같아야 한다. 장을 넘길 때 제목이 움직이면 조잡해 보인다.

`pptx_kit.content_slide()`의 기본 위치(헤드라인 0.6, 0.6 / 출처 0.6, 7.02)를 써도 된다. 어느 쪽이든 덱 전체에서 하나로 통일한다.

## 3. 글자 크기 4단계

| 단계 | pt | 용도 |
|---|---|---|
| D | 60–64 | 표지 제목, 핵심 숫자 |
| H | 32–36 | 헤드라인, 인용, 질문 |
| B | 20 | 본문, 라벨, 캡션. **이보다 작은 본문은 없다** |
| S | 12–14 | 출처, 축 눈금, 사진 크레딧, 쪽번호 |

- 글꼴은 한 가족만 쓴다. 영문 Segoe UI / Calibri, 한글 맑은 고딕 / Pretendard(발표 PC에 깔려 있을 때만). 굵기는 보통과 Semibold(또는 Bold) 둘만.
- 한글 덱은 `K.THEME.update(font='Malgun Gothic')`처럼 한글 글꼴을 지정한다. `pptx_kit.text()`가 동아시아 글꼴과 단어 단위 줄바꿈을 함께 설정한다. 숫자와 단위(`25 °C`, `100 mg/L`)는 줄바꿈 없는 공백(` `)으로 붙인다.
- 기울임은 학명·서명에만 쓴다. 밑줄은 쓰지 않는다.
- 줄 간격: 헤드라인 0.95, 본문 1.1.
- PowerPoint 기본 차트의 글꼴도 덱 글꼴로 고정한다(그대로 두면 다른 글꼴이 들어간다).

## 4. 색

| 역할 | 예시 HEX | 메모 |
|---|---|---|
| 밝은 배경 | F4F7F9 | 순백보다 프로젝터에서 덜 눈부시다 |
| 어두운 배경 | 0A1322 | 질문·결론·전환 장에만 |
| 글자 | 14202E / FFFFFF | 밝은 배경 / 어두운 배경 |
| 보조 글자 | 5B6B7C / 9FB2C4 | 캡션, 출처 |
| 비교 데이터 | B8C2CC | 대조군 막대·선. 글자색으로는 쓰지 않는다 |
| 선 | D9DEE3 / 2B3A50 | 0.75 pt 구분선 |
| 강조색 (하나) | 예: 3F7D2A / 8CCB5E | 밝은 배경용 / 어두운 배경용 한 쌍 |

- **강조색은 한 개, 뜻도 하나.** 예: 강조색 = 우리 제품·우리 데이터. 차트에서는 그 계열에만, 글에서는 장당 한 요소에만 쓴다.
- 회사 브랜드 색이 있으면 그것을 강조색으로 쓴다. 브랜드 색이 여러 개여도 덱에서는 하나만 고른다.
- 색을 고를 때는 후보 2–3개를 실제 슬라이드에 입힌 PNG로 보여 주고 사용자가 고르게 한다.
- 밝은 배경 위 강조색 글자는 대비 4.5:1 이상인지 확인한다.

## 5. 헤드라인

- 주어와 동사가 있는 주장 문장. 마침표 없이, 최대 2줄.
- 단서가 필요하면 헤드라인 안에 넣는다("예비 결과", "시험 조건에서").
- 숫자가 핵심이면 헤드라인에 숫자를 넣는다.

| 나쁜 예 | 좋은 예 |
|---|---|
| 시험 결과 | 처리 후 불량률이 4.2%에서 1.9%로 내려갔다 |
| 시장 현황 | 검사에 드는 시간의 60%가 시료 준비에 쓰인다 |
| Results of PCA | Treated samples separate from controls within one day |

## 6. 슬라이드 틀 4가지

| 틀 | 구성 | 쓰는 곳 | 최대 단어 |
|---|---|---|---|
| A 사진 전면 | 사진이 화면 전체. 글은 사진의 빈 곳에, 그쪽에만 그라데이션 | 표지, 인용, 질문, 마무리 | 25–35 |
| B 분할 | 왼쪽 40% 사진(가장자리까지), 오른쪽 헤드라인 + 큰 숫자 1–3개와 라벨 | 사례, 대상 소개 | 30–45 |
| C 밝은 내용 | 헤드라인 + 그래프 하나(또는 도형 그림) + 캡션 한 줄 | 데이터 장 | 30–45 |
| D 어두운 진술 | 어두운 배경, 큰 문장 또는 단어 2–3개와 짧은 설명 | 한 줄 메시지, 결론, 요청 | 35–45 |

- 데이터 장(C)은 "왼쪽 그림 + 오른쪽 글 칼럼"으로 써도 된다. 글 칼럼은 3덩어리 이하, 얇은 구분선으로 나눈다.
- 큰 숫자(D 단계)는 장당 3개까지. 숫자 옆 라벨은 두 줄: 첫 줄 본문색(무엇의 숫자인가), 둘째 줄 보조색(비교 기준·조건).
- 표가 필요하면 4행 × 4열 이하로 줄이고, 볼 칸에만 강조를 준다. 큰 표는 백업으로 보낸다.
- 설명이 순서대로 쌓여야 하는 장은 `click_fade`로 한 줄씩 나오게 한다.

## 7. 사진

- 실사만 쓰고 가장자리까지 채운다(전면 또는 한쪽 패널). 원형 크롭, 테두리, 그림자를 쓰지 않는다.
- 사진 전체를 어둡게 하지 않는다. 글자가 놓이는 쪽에만 한 방향 그라데이션을 넣는다: `K.cover_photo(slide, path, 0, 0, 13.333, 7.5, focus=(0.5, 0.4), grad=('left', 0.85, 0.0, '0A1322'))`.
- 가능하면 하늘·배경처럼 사진에 원래 있는 빈 곳에 글자를 둔다. `focus`로 자르는 위치를 조정하고 렌더해서 확인한다.
- 크레딧은 출처 줄에 "Photo: …"로 적는다. 사용 권한이 불확실한 사진은 쓰지 않고 사용자에게 묻는다.
- 생성 이미지·스톡 사진으로 빈 곳을 채우지 않는다. 맞는 사진이 없으면 글과 그림만으로 간다.

## 8. 그래프

- 한 그래프에 메시지 하나. 말할 계열만 강조색, 나머지는 회색.
- 축 제목과 단위를 넣는다. 눈금선은 연한 선 0.75 pt 또는 없음. 범례 대신 선·막대 옆에 직접 라벨을 붙인다.
- 막대그래프의 축은 0에서 시작한다. 0에서 시작하면 차이가 안 보이는 데이터는 선·점 그래프로 바꾸고 축 범위를 캡션에 밝힌다.
- 그림 안 제목은 뺀다(헤드라인이 제목이다). 글자는 슬라이드에 올렸을 때 14 pt 이상으로 보이게 키운다.
- 오차 막대가 있으면 무엇인지(SD, SE, 95% CI)와 n을 캡션에 적는다.
- 여러 항목 × 여러 조건이면 선 그래프 여러 개보다 heatmap 하나가 읽기 쉽다. 색 스케일은 덱 전체에서 고정한다.
- matplotlib으로 그릴 때는 배경 투명 또는 슬라이드 배경색, 300 dpi, 덱과 같은 글꼴.

## 9. 출처와 쪽번호

- 출처 줄은 S 단계 한 줄(약 120자 이하). "Author Year" 또는 "자료: 기관, 연도"만 쓰고 장당 3개까지.
- 자기 데이터는 "자사 시험, 2026, n = …"처럼 조건과 함께 적는다.
- 전체 서지·상세 조건은 맨 뒤 백업 "References / 자료 출처" 장으로 옮긴다.
- 쪽번호는 내용 장에만 넣는다. 사진 전면 장에는 넣지 않는다. 푸터 띠, 장마다 반복되는 로고는 넣지 않는다(템플릿이 요구하면 따른다).

## 10. 쓸 수 있는 도형

사진, 직각 사각형(막대·배경 면), 0.75 pt 선, 화살표, 타임라인 점. 이것으로 안 그려지는 것은 그림 파일로 만든다.
둥근 카드와 꺾쇠 화살표 띠는 쓰지 않는다. 남는 공간은 채우지 않는다.
